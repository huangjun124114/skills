# 六环节行业研究框架（Industry Research, 6-Section Framework）

用户自带的一套投研/战咨双背景的行业研究模板。**核心不是写下什么，而是按它的纪律写**——
违反纪律的输出等于没写。

> **与 MOSS 行业研究专家协同**：若当前会话已选择 Expert「MOSS增长谋士」（moss-industry-research），其 `industry-research` skill 才是研究方法、`research_state`、证据标准与质量门的**唯一真源**。本 skill 仅承载用户自带的「六环节」章节骨架与数据纪律（可映射为 HTML 报告的章节结构），Plan / 审批 / delivery_manifest / HTML 交付一律走专家流程，不得用本 skill 的流程覆盖专家流程。

## 零、前置对齐（必做，不可跳过）

动笔前必须向用户确认六项，缺项直接问，**不许自行假设**：

| # | 项 | 缺失影响 |
|---|---|---|
| ① | 企业名称与主营业务（一句话：卖什么给谁） | 全文无主体 |
| ② | 所处行业（越具体越好，"商用厨电中的商用洗碗机"而非"家电"） | 第一/二/四环节边界与链条全错 |
| ③ | 研究目的（融资 / 进入新市场 / 产品立项 / 竞品防御 / 年度规划） | 决定"启示"与行动清单方向 |
| ④ | 对标企业（如有） | 第六环节只能做行业均值对标 |
| ⑤ | 数据时间基准（以哪一年为"当前年"） | 所有"近五年/未来三年"取数窗口 |
| ⑥ | 市场范围（中国大陆 / 全球 / 含出海） | 规模口径 |

**执行要点**
- 用 `AskUserQuestion` 一次问 4 项（工具上限），其余 2 项用「我的理解 + 待确认」在正文里收口。
- 问之前先做工作区侦察（Glob / 已有 memory），能自己推出来的项标成"我的理解，如有误请纠正"，不要反问用户已知的东西。
- 已确认项写成一张对齐表回显，让用户有机会纠偏。

## 一、全局质量红线（逐条检查）

1. **数据纪律**：每个关键数字 = 数值 + 来源机构 + 年份 + 统计口径。查不到写「无公开数据」，并说明替代依据。宁标缺口，不给假数字。
2. **结论纪律**：每个环节开头先给 ≤3 条核心判断，再展开。只罗列现象 = 不合格。
3. **信息分级**：事实 / 他人观点 / 我的推断，三类分别标明。推断必须写出推理链条与成立前提。
4. **语言纪律**：禁止「随着……的发展」「在当今快速变化的时代」。每句承载信息量。
5. **图表纪律**：每环节 ≥1 张图，写法统一为「图表类型 + 横纵轴字段 + 数据来源 + 这张图要证明的观点」。数据不可得 → 改用定性矩阵 / 阶段条形图 / 气泡图**手工标注**，不许凭空造图。
6. **交付纪律**：**六环节分六次交付，每次只写一个环节，等用户确认再继续。严禁一次性输出全部内容。**
7. **反向自检**：每环节末尾三句话——最可能错的判断是哪个 / 错了会导向什么错误决策 / 验证它需要什么数据。

## 二、统一段落模板（每环节照此输出）

```
【结论卡】≤3 条核心判断，每条一句话
【正文】按框架问题逐条回答，单条 150–300 字，有论点有证据
【数据表】可结构化信息做表，标字段与来源
【图表】类型 + 字段 + 来源 + 要证明的观点
【对我们的启示】1–3 条，每条落到 动作 / 预期收益 / 责任角色
【待验证项】不确定假设 + 验证方式
【反向自检】三句话
```

## 三、六环节框架

### 第一步 行业定义与边界
一句话定义 + 三句背景（因何出现 / 当前状态 / 为什么现在值得研究）；根本理由（用户需求侧 + 社会功能侧；判断刚需 / 效率改进 / 纯情绪消费）；边界界定（**明确属于 / 明确不属于 / 跨界模糊**三清单，模糊地带要说清归属分歧点）；分类维度 3–5 个（人群 / 功能 / 商业模式 / 场景 / 价格带）并列各细分**规模占比与增速差异**；与相邻行业区别 ≥2 组，指出独特识别点。

### 第二步 驱动因素
推动力清单（技术 / 政策 / 文化 / 代际 / 平台，各 1–2 个：作用机制 + 强度强中弱 + 可观测证据）；用户核心驱动力（按人群分层，要行为数据或调研证据，拒绝"因为方便所以用"）；发展阶段 3–5 段（标志事件 + 技术条件 + 竞争格局 + 用户特征，时间线呈现）；关键变量跃迁 2–3 个（如智能手机普及、移动支付、短视频媒介），说清跃迁前后结构性差异；增强回路 2–3 组（画正反馈路径，回答飞轮是否转起来、前提条件、哪个条件消失就停）；资本与政策（近五年代表性融资事件与金额 + 关键政策文件名与核心条款；判断扶持期 / 规范期 / 收紧期及依据）；底层逻辑稳定性（增长依赖什么，是否单一变量；可持续性判断与边界条件）；未来 5–10 年趋势 3–5 个（配数据预测或可比市场历史经验）；成熟市场参照 1–2 个（渗透率 / 集中度 / 盈利模式 / 用户结构差异，提炼三条可操作借鉴）。

### 第三步 发展空间
市场规模（当前规模 + 口径来源 + 近五年 CAGR + 未来三年/五年预测，**必须写模型与关键假设**）；见顶信号（增速放缓 / 需求外溢 / 地域扩张边际递减，用数据回答）；生命周期判断（导入/成长/成熟/衰退 + 至少三条依据：技术成熟度、用户认知度、资本热度、龙头格局稳定性）；用户教育状态（还有多少未被教育，模式是否定型，有无可复制模板）；渗透率（当前 + 成熟市场参考 + 剩余空间，判断是否落在 5%–25% 红利加速区）；复购与粘性（复购率 / 留存率 / 频次变化，尝鲜转习惯还是一锤子买卖）；集中度（CR4 / CR8 及近三年变化，寡头/双寡头/充分竞争）。

### 第四步 产业链
链条结构（上层/中层/下层功能定位与代表企业，**谁是链主、链主掌控了什么**）；利润结构（各环节毛利率、净利率、周转、账期，横向表格）；壁垒类型（资本密集 / 技术密集 / 品牌渠道，尽量量化门槛：初始投资额、认证周期、客户切换成本）；定价权归属（依据：稀缺性 / 专利 / 渠道控制 / 品牌溢价 / 标准制定权）；**微笑曲线验证**（价值集中在哪端，是否存在反例——利润反而在制造环节）；结构重构（谁被削弱谁被加强：中间商被跳过、制造自动化、AI 替代设计或客服、渠道去中心化）；模式卡位（平台型 / 垂直整合型 / 分销型 / 代工型 / DTC 型各卡在哪、优势与天花板）；机会洼地 1–3 个（门槛适中、竞争未充分展开，说明依据与进入方式）。

### 第五步 环境分析（PEST）
每维度统一四要素：**事实 → 影响方向 → 影响强度 → 时间窗口**。
- 政策：支持性清单（文件名 + 核心条款 + 实际力度）、限制性清单、窗口期还是收紧期、周期判断、监管空白地带及可利用性
- 经济：周期性利多/利空、需求依赖居民可支配收入还是资本热度、通胀/利率/汇率传导路径、下行周期抗压性
- 社会文化：人口结构（老龄化、Z 世代、家庭小型化）、环保/健康/可持续是推动力还是成本项、性价比→情绪价值的转向影响、地域文化差异
- 技术：**必须写具体技术名**（大模型、具身智能、固态电池、柔性显示……），不许写"AI 技术"；说明是否打破原有壁垒、是否降低准入门槛、能否形成规模效应、落地瓶颈

### 第六步 典型企业
选样理由（头部地位 / 模式代表性 / 所处阶段 / 可比性 / 启示价值，五个角度各一句）；财务对标（先列行业通用对标指标清单四类：盈利能力、增长性、效率与成本、资产结构与风险；再给目标企业实际值 vs 行业均值并**解释差异来源**）；业务规模（营收、净利、员工数、渠道数、用户量、会员占比、增长率、用户分布、产品结构、SKU 与单品表现）；价值主张与模式（解决谁的什么问题、能否一句话说清、卖产品/卖服务/做平台/订阅、差异化战略）；能力沉淀三条链（价值创造 / 价值传播 / 价值交付）；未来 3–5 年战略（增长目标、新业务、投资并购出海、外部风险预案）；对我们的影响与启发（可借鉴打法具体到机制动作 / 差距识别按战略·能力·组织·认知四维 / 战略建议含取舍逻辑 / **90 天行动清单**）。

## 四、最终整合
六环节全部确认后，输出**单文件 HTML 报告**：
1. 一页纸摘要：五条核心判断 + 三条行动建议
2. 六环节正文，保持前述段落结构
3. 附录：数据来源清单、待验证假设清单、图表索引、**适用边界与失效条件**

## 五、执行环境注意事项（Windows / WorkBuddy）

- **bash 可能不可用**：本机 `sh` 缺 coreutils（`ls`/`head`/`date` 全无）。文件操作一律用 Glob / Read / Write / Edit；命令用 PowerShell 工具。
- 图表渲染：用 `show_widget` 内联（先 `read_me` 载入 `diagram,chart` 模块）。深色主题用 ramp 800 填充 + 200 描边 + 100 文字。
- **自查数字**：图例/标注里的区间端点极易写错（左端被误写成别的数）。渲染后回读一遍每个数字。
- 建议随研究进程把每轮的硬数据落到工作区 `.workbuddy/memory/YYYY-MM-DD.md`，因为最终 HTML 要写"数据来源清单"。

## 六、常见错误（血泪）

1. 一次性把六环节全写完 → 违反交付纪律，用户无法逐段纠偏。
2. 市场规模直接引用咨询公司软文数字 → 同一时点同口径可能差 3 倍。**必须做口径冲突表**并说明为什么自建口径。
3. "所处行业"写得过泛 → 边界和产业链全错。
4. 图表里的数字与正文不一致 → 报告可信度崩塌。
5. 把跨界模糊地带（硬件、金融、流量）算进 TAM → 规模高估 2–3 倍。
