# 家庭相册整理专家 · Photo Archive Organizer

> 把几千张散乱照片，整理成 `201809-动物园孔雀（AI整理）` 这样能直接看懂的结构化相册。

**已在一个真实的 6,763 张家庭照片项目上完整跑通**：最终产出 2,545 张精选照片 / 100 个事件文件夹 / 8.74 GB，六道检验闸门全部通过，零内容丢失。

---

## 它解决什么问题

手机、相机、微信、网盘积攒下来的照片，通常长这样：

- 文件名是 `IMG_8142.HEIC`、`mmexport1677923596872.jpg`，看不出时间和内容
- 一部分照片没有 EXIF，也看不出拍摄日期
- 一个文件夹里混着几千张，跨了好几年、好几个事件
- 里面夹着截图、票据、PPT、工作培训照
- 同一个场景连拍了 20 张

手工整理会耗掉几个周末。这个技能把整个过程变成一条可复现、可校验、可回滚的流水线。

## 两种模式

| | **模式 A：迁移合并** | **模式 B：筛选归档** |
|---|---|---|
| 适合 | 多个人的照片合并成家庭相册 | 从大量照片里挑出好看的 |
| 动作 | **迁移**，一张不丢 | **筛选**，大量剔除 |
| 命名 | `YYYYMM-事件-来源` | `YYYYMM-事件名（AI整理）` |
| 典型场景 | 「把帅哥和闺女的照片合到一起」 | 「几千张里挑出值得留的，按事件分好」 |

两种模式可以**串联**使用：先 B 精选，再 A 合并进大相册。

## 六个核心能力

**1. 多源日期推断，不靠文件时间**

EXIF → 文件名日期 → 13 位时间戳 → XMP → 文件夹名 → iPhone 序号插值，五层客观信号依次尝试。
插值必须过留一验证（准确率 98.4% 才启用）。**绝不使用 mtime/ctime** 猜测。
实测覆盖率 97.7%，推断不出的按规则排除，不硬猜。

**2. 事件聚类**

同月内按日期连续性切分会话，超过 70 张时用 Ward 凝聚聚类在「视觉特征 + 时间坐标」上拆分为子事件。禁止跨月合并。

**3. 质量精选**

清晰度、分辨率、信息熵、色彩丰富度、曝光的加权排序，超出上限时保留最好的 N 张。连拍自动去重。

**4. 内容语义清理（无视觉方案）**

看不到图也能判断内容：用**上一轮的成果做免费标注**训练判别器，再按文件夹名分档，最后生成 HTML 复核表交给你拍板。
实测区分度 AUC 0.85–0.87，能分辨「团队拓展（真办公，0.84）」和「长城团建（户外旅游，0.27）」这种光看名字分不出的情况。

**5. 六道检验闸门**

内容守恒 / 去重 / 上下限 / 备份校验 / 隔离区对账 / ctime 审计。每轮结束必跑，不过就停。

**6. 全程可回滚**

所有剔除先入隔离区，删除源文件必须同时满足「已归档」和「备份字节一致」两道条件。实测 2,677 次删除，零误删。

## 快速开始

```bash
# 模式 B（筛选归档）主干流程
python scripts/date_infer.py       --root 照片目录 --out dated.json --apply
python scripts/extract_features.py --dated dated.json --out feats.json \
                                   --visual-out visual.npy --apply
python scripts/cluster_events.py   --feats feats.json --visual visual.npy \
                                   --out events.json --apply
#   人工命名事件 → 写入归档区
python scripts/verify_gates.py     --archive 归档目录 --cap 40 --min-files 3
```

跑通主干后再逐步加能力：质量精选、语义清理、源目录回收。首次使用建议先跑 SKILL.md 第 3.1 节的**最小可行路径**。

所有脚本默认**干跑**，加 `--apply` 才写盘；路径全部参数化，不硬编码任何目录。

## 安全设计

| 机制 | 说明 |
|---|---|
| 四区隔离 | 源区只读、归档区只增、隔离区可回滚、备份区全程只读 |
| 双闸门 | 删源文件必须「已归档 **且** 备份字节一致」，容忍度 0 |
| 验证隔离 | 已完成整理的目录列为只读，测试一律复制子集到临时目录 |
| 异常处置 | 10 类异常各有判据、动作、回退点 |
| 人在回路 | 批量删除前分档提问，每个选项都给具体数字 |

## 已知边界

- **需要人工命名**：事件名必须你来看图后定，模型无法替代
- **纯背景照片会被判别器误判**：儿童证件照得分可达 0.99，已内置保护名单机制，但仍建议复核表过一眼
- **质量分只在同一批照片内有效**：做了 z-score 归一化，不可跨数据集比较
- **艺术性虚化、夜景可能被质量分误伤**：淘汰前建议看一眼排名末尾
