# 判别器配方（classifier-recipes）

模型无法查看图像时，用判别器替代人眼做内容判定。**核心技巧：用上一轮的成果做免费标注**——这是多轮迭代越做越准的原因。

## 一、通用配方

### 步骤 1　构造标注（零人工成本）

| 样本 | 来源 |
|---|---|
| **正样本（保留）** | 归档区中语义明确的文件夹；或第一轮人工复核后保留的文件 |
| **负样本（剔除）** | 隔离区中对应的被剔除文件 |

> 判别"办公场景"时：负样本 = 隔离区中事件名为工作类的文件；正样本 = 归档区中纯家庭/纯旅游文件夹的文件。
> 判别"文档截图"时：负样本 = 隔离区全部文件；正样本 = 归档区全部文件。

### 步骤 2　特征集（12 维，512px 缩略图上计算）

| # | 特征 | 计算 |
|---|---|---|
| 1 | 平均饱和度 | HSV 的 S 通道均值 |
| 2 | 白底占比 | `V > 235` 的像素比例 |
| 3 | 纸面占比 | `(V > 225) & (S < 40)` 的像素比例 |
| 4 | 文字边缘密度 | `(|∇x| > 40).mean()` 与 `(|∇y| > 40).mean()` 的平均 |
| 5 | 平坦区域比 | 3×3 拉普拉斯响应绝对值 < 4 的比例 |
| 6 | 灰度熵 | 32 bin 直方图香农熵 |
| 7 | 灰度标准差 | — |
| 8 | 长宽比 | `min(w,h) / max(w,h)` |
| 9 | 屏幕比例距离 | 与 `[9/16, 9/19.5, 9/20, 9/21, 3/4, 2/3, 16/10, 16/9, …]` 的最小绝对差 |
| 10 | 像素数 | `log10(w*h + 1)` |
| 11 | 是否 PNG | 手机截图几乎都是 PNG |
| 12 | 是否 HEIC | — |

### 步骤 3　训练与评估

`StandardScaler + LogisticRegression(max_iter=2000, class_weight="balanced")`，5 折分层交叉验证，报告 AUC。

### 步骤 4　选阈值（**禁止自动选**）

打印阈值对照表，人工选工作点：

```
thr   精确率   召回    真实照片误杀率
0.30  0.431   0.894   43.1%
0.50  0.585   0.712   18.4%
0.55  0.626   0.660   14.4%   ← 常用工作点
0.70  0.721   0.532    7.5%
```

**反面案例**：按"召回 ≥ 0.95"自动选阈值，选到 0.20——文档召回 0.96，但误杀 **62%** 的真实照片（731 张候选只剩 145 张）。自动选阈值必然踩这个坑。

### 步骤 5　合理性验证

按文件夹看剔除分布，判断是否符合直觉：

- 纯游玩事件（动物园、溶洞、竹筏）应**接近零剔除**
- 疫情期事件（2020–2022，健康码/预约截图多）应**剔除较多**

若分布相反，说明标注或特征有问题，不要继续。

### 步骤 6　保护名单（铁律）

**判别器分数再高，只要在保护名单里就绝不动。**

## 二、已验证实例

### 实例 1：文档 / 截图判别器

| 项 | 值 |
|---|---|
| 正样本 | 归档区 2,150 张 |
| 负样本 | 隔离区 785 张 |
| AUC | **0.846** |
| 采用阈值 | 0.55（召回 0.66 / 精确率 0.63 / 误杀 14.4%） |
| 效果 | 731 张候选中剔除 198 张文档 |

### 实例 2：工作场景判别器

| 项 | 值 |
|---|---|
| 正样本 | 纯家庭/旅游文件夹 2,242 张 |
| 负样本 | 隔离区工作类事件 551 张 |
| AUC | **0.874** |
| 效果 | 从 2,661 张中定位 116 张办公/培训照 |

**这个判别器最有价值的输出**：`团队拓展` 得分 **0.84**（真办公场景）vs `长城团建` 得分 **0.27**（户外旅游照）。都叫"团建"，删除决策必须相反——这正是判别器相对于"只看文件夹名"的增量价值。

## 三、已知的必误判场景（保护名单候选）

**纯背景 / 白底照片一定被误判为文档或工作场景**，因为判别器识别的就是"大面积平坦、低饱和度"。

| 文件夹 | 工作场景得分 | 真相 |
|---|---|---|
| 儿童证件照 | **0.99** | 孩子的证件照（棚拍纯背景）→ 家庭，必须保留 |
| 生日聚会 | 0.65 | 室内聚会 → 家庭 |
| 儿童制服照 | 0.60 | 孩子的制服照 → 家庭 |

建立保护名单时至少覆盖：证件照、制服照、聚会、舞蹈课、演出/汇演（舞台背景也可能是纯色）。

## 四、人在回路复核

判别器给出的是**提议**，不是决定。批量删除前：

1. 生成联系表（缩略图网格 + 文件夹名 + 判别分数标签，红色标注 ≥0.7）
2. 按"档位"向用户提问，每档给出**具体数字**让用户选
3. 用户确认后才执行，且先入隔离区

联系表规格建议：190px 缩略图、5 列 × 6 行、标签为「事件名 + 分数」。
