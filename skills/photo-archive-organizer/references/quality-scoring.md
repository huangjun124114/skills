# 质量评分（quality-scoring）

用于 P6 排序。实现见 `_common.quality_score()`，`extract_features.py --apply` 输出的 `q` 字段即此值。

## 铁律

**质量分只在同一个候选池内部有效，绝对值不可跨数据集比较。**
所有分量都做了 z-score 归一化（减去本池均值、除以本池标准差），换一批照片算出来的 `q=0.5` 含义完全不同。禁止拿不同轮次的 `q` 做横向对比。

## 分量与权重

| 分量 | 含义 | 计算 | 权重 |
|---|---|---|---|
| `sharp` | 清晰度 | 3×3 拉普拉斯响应的**方差** | **+0.35** |
| `px` | 分辨率 | `log10(宽 × 高 + 1)` | **+0.20** |
| `ent` | 细节丰富度 | 32 bin 灰度直方图的香农熵 | +0.15 |
| `colour` | 色彩丰富度 | Hasler-Süsstrunk 指数 | +0.15 |
| `dark` | 欠曝惩罚 | 灰度 < 20 的像素占比 | −0.075 |
| `blown` | 过曝惩罚 | 灰度 > 250 的像素占比 | −0.075 |
| `is_png` | 截图嫌疑 | PNG 格式置 1（手机截图几乎都是 PNG） | −0.10 |

Hasler-Süsstrunk 色彩指数：

```
rg = R − B
yb = 0.5(R + B) − G
colourful = sqrt(std(rg)² + std(yb)²) + 0.3 × sqrt(mean(rg)² + mean(yb)²)
```

## 计算流程

1. 对候选池内每张图算出 7 个**原始值**；
2. 对每个分量在整个池上做 z-score；标准差 < 1e-9 的分量（全部相同）置 0，避免除零；
3. 按上表加权求和得到 `q`；
4. 按 `q` 降序排名写入 `q_rank`，从 0 开始。

```python
z = (raw - raw.mean()) / raw.std()      # per component, over the pool
q = (0.35*z_sharp + 0.20*z_px + 0.15*z_ent + 0.15*z_colour
     - 0.075*z_dark - 0.075*z_blown - 0.10*z_is_png)
```

## 已知局限

| 场景 | 表现 | 处理 |
|---|---|---|
| 艺术性虚化（人像背景虚化） | 被判低分 | 排序靠后可能被误淘汰；重要事件建议人工看一眼排名末尾 |
| 夜景、烟火、逆光 | 欠曝惩罚误伤 | 同上 |
| 高灰度扫描件 | 熵高但无意义 | 由语义清理环节剔除，不依赖质量分 |
| 不同来源混合（手机 + 单反） | `px` 差异主导 | 若来源差异大，考虑按来源分组各自排序 |

## 使用建议

- **只对超出上限的事件启用**：事件内照片数 ≤ 上限时全部保留，不做淘汰。
- **近重复抑制仅在超限时启用**：连拍去重（余弦距离 < 0.035）若无条件启用，会把事件压到下限 5 张以下，违反规则。
- 淘汰前先看一眼排名最末的 5–10 张，确认不是艺术性虚化之类的误判。
