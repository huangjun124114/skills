# 报告与映射表模板（report-template）

各阶段落盘产物的参考格式。

## 1. 扫描报告（模式 A `scan.py` / 模式 B 自建）

```
# 扫描报告：<root>
总文件数: N
根目录松散文件: M
无扩展名文件(全树): K

## 顶层目录
- <dir>: <count> 文件 | jpg:.., mp4:.., ...
## 全树扩展名分布
- .jpg: ..
## 初步计划（只读，未修改任何文件）
1. 确认合并映射 / 过滤规则 ...
2. 备份校验后执行 ...
3. 待溯源后续询问用户 ...
```

## 2. 迁移映射表（模式 A，CSV）

| 列 | 含义 |
|---|---|
| 原路径 | 源文件绝对/相对路径 |
| 目标文件夹 | `YYYYMM-事件-来源` 或 `待溯源-来源` |
| 年月 | 推断出的 YYYYMM |
| 日期依据 | folder-name / filename-date / exif / video-mvhd / age-inference |

## 3. 待溯源分析表（模式 A，CSV+MD）

| 列 | 含义 |
|---|---|
| item | 相对 pending 目录的路径 |
| subfolder | 直属子文件夹名（事件候选来源） |
| event_candidate | 去掉日期前缀后的事件名 |
| filename_date | 文件名解析出的日期 |
| media_date | EXIF/mvhd 解析出的日期 |
| suggested_folder | 建议目标文件夹 |
| confidence | high / medium / low |
| needs_user | yes / no（yes 必须询问用户） |

`needs_user=yes` 汇总后，用 AskUserQuestion 或对话清单请求分类建议，写入建议映射 CSV 后执行。

## 4. 过滤与精选统计（模式 B）

| 阶段 | 数量 |
|---|---|
| 源区原始文件总数 | N |
| 大小越界过滤掉 | N |
| 非图片格式过滤掉 | N |
| 进入候选 | N |
| 无法推断日期（排除） | N |
| 聚类后 <5 张的会话（排除） | N |
| 聚类结果 | N 事件 / N 张 |
| 质量精选后 | N |
| 已判废去重（隔离区命中） | N |
| **本轮写入归档区** | **N** |

## 5. 语义清理决策表（模式 B，每轮一张）

| 档位 | 内容 | 判别均分 | 决策 | 数量 |
|---|---|---|---|---|
| 一 | 文件夹名明确为 X 类 | 0.84 | 整组删除 | N |
| 二 | 名称与内容不符的疑似类 | 0.27 | 保留 | 0 |
| 三 | 混合文件夹 | 0.35 | 只删 ≥0.7 | N |
| 四 | 散落在保留文件夹的高分项 | ≥0.8 | 全部删除 | N |

## 6. 删除清单（CSV，销毁前必出）

| 列 | 含义 |
|---|---|
| 源文件 | 待删源文件绝对路径 |
| 备份文件 | 备份区中对应的镜像路径 |
| MD5 | 两者共同的 md5（校验通过才有此行） |
| 字节大小 | — |
| 归档区位置 | 该文件在归档区的落点 |

**未通过备份校验的行不进入本清单**，单独列 `unverified` 并在报告中说明。

## 7. 最终核验报告

```
=== 归档区最终状态 ===
文件夹 N 个   照片 N 张   N.NN GB
最少 N 张 (<folder>)   最多 N 张 (<folder>)
少于 3 张: 无
空文件夹: 无
内部 md5 重复: 0 组

=== 六道闸 ===
1 内容守恒        该留却不见了 0 张            ✅
2 去重            归档区 md5 重复 0 组         ✅
3 上下限          无超限 / 无 <3 张 / 无空     ✅
4 备份闸门        N/N 校验通过，0 不可校验     ✅
5 隔离区对账      唯一 md5 N == 预期移除 N     ✅
6 ctime 审计      各批次写入量与预期一致       ✅

=== 备份区 ===
N 个文件，完好未动                              ✅
```
