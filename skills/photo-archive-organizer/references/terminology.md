# 术语与四区模型（terminology）

全文统一使用本文件的术语。旧版混用「目标目录 / 归档区 / 整理后」「隔离区 / quarantine / 待溯源」等叫法，已废弃。

## 一、四区模型

任何一次整理都涉及四个区域，职责和读写权限严格区分：

| 区域 | 英文 | 作用 | 权限 |
|---|---|---|---|
| **源区** | source | 待整理的原始目录 | 全程只读；仅在回收阶段（P8）才删除，且需双闸门 |
| **归档区** | archive | 最终相册，如 `整理后/YYYYMM-事件名/` | 只增不改；写入必须幂等 |
| **隔离区** | quarantine | 被剔除但可还原的暂存区，按轮次建子目录 | 可写；定期按 md5 去重 |
| **备份区** | backup | 源区的完整字节级副本 | **全程只读，任何情况下不得修改** |

关键点：

1. **隔离区是"软删除"**。所有剔除操作先入隔离区，确认无误后才可真正销毁。
2. **备份区是最后防线**。删除源区文件的唯一凭据是"该文件在备份区存在且 md5 一致"。
3. **归档区与隔离区可以存在同名文件夹**。混合事件中只有部分文件被剔除时，归档区保留保留集、隔离区存放剔除集，两边同名是正常的，判定去留时必须"按文件 md5"而非"按文件夹名"。

## 二、核心术语

| 术语 | 定义 |
|---|---|
| **事件** | 一次归档单元，对应一个文件夹。由时间连续性 + 视觉相似性聚类得到 |
| **会话** | 中间概念：同月内连续天数间隔 ≤ 2 天的一组照片，是切分事件的原料 |
| **上限 N** | 单个事件最多保留的照片数，超出部分按质量分降序淘汰。默认 40，用户可调至 60/80 |
| **下限** | 事件最少 5 张才成立（否则并入最近邻或丢弃）；归档文件夹最少 3 张（否则删除该文件夹） |
| **质量分** | 清晰度 / 分辨率 / 熵 / 色彩丰富度 / 曝光的加权分，用于排序，**绝对值不可跨数据集比较** |
| **判别器** | 用上一轮结果自标注训练的二分类模型，替代人眼做内容判定 |
| **保护名单** | 人工指定的文件夹集合，**无论判别器给多少分都不得删除** |
| **闸门** | 强制执行的前置校验条件，不通过则阻断后续操作 |
| **轮次** | 一轮完整的"扫描→推断→聚类→精选→清理→写入→检验"。多轮迭代时，上一轮的成果成为下一轮的标注数据 |
| **ctime 审计** | 按文件创建时间分组，核对每轮实际写入量的审计手法 |

## 三、两种作业模式

| | 模式 A：迁移合并 | 模式 B：筛选归档 |
|---|---|---|
| 目标 | 多个来源目录合并成共享相册 | 单批散乱照片精选成主题相册 |
| 动作 | **迁移**，一张不丢 | **筛选**，大量剔除 |
| 命名 | `YYYYMM-事件-来源` | `YYYYMM-事件名（AI整理）` |
| 特征模块 | 来源后缀映射、待溯源协议 | 规则过滤、质量精选、语义清理、上下限 |
| 备份 | 技能自行创建 | 用户已有，技能只校验 |
| 判定去留依据 | 能否推断日期 | 日期 + 内容语义 |
